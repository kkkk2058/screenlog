# screenlog — 프로젝트 영상 나레이션 대본

영상 자체는 **무음 + 온스크린 텍스트**로 완결된다. 이 대본은 목소리를 얹고 싶을 때 쓰는
선택 사항이다.

**타임코드는 실제 컷 전환 시각이고, 대사 길이는 한국어 발화 속도 약 5자/초로 맞춰 썼다.**
녹음해보면 어딘가는 반드시 넘치거나 남는다 — 그때는 대사를 줄이지 말고
[`src/compose.py`](src/compose.py)의 `FULL` / `RECAP` 테이블에서 해당 컷의 초를 고치고
다시 렌더하는 쪽이 낫다. 컷 길이는 그러라고 한 곳에 모아뒀고, `capture.py`도 같은
테이블을 읽어서 필요한 만큼만 프레임을 찍는다.

```bash
cd docs/video/src && PY=.venv/bin/python ./build.sh
```

## 어떻게 만들어졌나

정지 이미지를 이어 붙인 슬라이드쇼가 아니다. **모든 컷이 프레임 시퀀스**다.

| 단계 | 하는 일 |
|---|---|
| [`capture.py`](src/capture.py) | Playwright로 30fps 프레임을 뜬다. 실시간 녹화가 아니라 Web Animations API로 **애니메이션 시각을 프레임마다 직접 찍는** 결정적 캡처라, 프레임 드랍이 없고 몇 번을 다시 돌려도 같은 결과가 나온다 |
| [`motion.css`](src/motion.css) | 등장 모션. 이징을 `--ease` 하나로 통일했다 — 요소마다 곡선이 다르면 “여러 사람이 만든 화면”처럼 보인다. 스태거 순서는 문서 순서대로 런타임이 자동 부여한다 |
| [`compose.py`](src/compose.py) | 프레임 → 클립 → 크로스페이드 체인. 어두운 그라데이션의 밴딩을 덮으려고 아주 약한 필름 그레인을 얹는다 |

**기능 5종(`00:51`~`01:28`)은 실행 중인 실제 대시보드다.** 가상 시계(`page.clock`)를
33ms씩 밀면서 프로덕션 `dashboard.html`이 그리는 화면을 그대로 찍는다 — 질문이 한 글자씩
타이핑되고, 토큰이 흐르고, 근거가 펼쳐지는 것 전부 원본 렌더링 코드가 한 일이다.

**수치는 0에서 올라간다.** `0.99`, `1.4초`, `−97.7%`가 카운트업으로 차오른다.
숫자가 그냥 나타나면 정보지만, 올라가면 성과로 읽힌다.

### 캡처 입력은 어떻게 얻었나

1. `capture_answers.py` — `api.py`가 부르는 것과 같은 진입점(`ask_auto`)으로 5개 질문을
   실제로 물어서 답변·라우팅·소요 시간을 받는다. 슬랙 턴은 앞 턴을 `history`로 넘겨서
   “직전 답변 재사용” 경로를 그대로 탄다.
2. `dump_fixtures.py` — 사이드바가 쓰는 `/api/stats`·`/api/digest`·`/api/timeline` 응답과
   검색 근거(hits)를 같은 함수로 받는다.
3. `build_harness.py` — 프로덕션 `dashboard.html` 원본에 위 응답을 물려 `harness.html`을 만든다.

> 대시보드가 Basic Auth 뒤에 있어서 HTTP를 거치지 않고 함수를 직접 불렀다.
> 답변·통계·근거는 전부 실제 값이고, 화면은 실제 렌더링 코드가 그린 것이다.
> `fixtures.json`/`answers.json`은 마스킹 전 원문이라 **저장소에 안 들어간다**(`.gitignore`).

**공개용 마스킹** — `build_harness.py`의 `REDACT`에 모여 있다.

| 가린 것 | 왜 |
|---|---|
| 크롬 프로필 접미사 (`- Chrome - sehoon (…)`) | 근거 카드 **모든 줄**에 이름과 계정이 붙어 나온다 |
| 제3자 이름 (`김성용 교수님` → `김○○ 교수님`) | 본인이 아닌 사람 |
| `김세훈님` → `동료` | 사이드바 “최근 기록”에 노출 |
| EC2 공인 IP | 슬랙 초안 본문에 그대로 실림 |
