Mac에 설치하기

화면 활동을 기록해서 나중에 검색하고 물어볼 수 있게 해주는 메뉴바 앱입니다. 녹화기와 조작 메뉴가 한 앱에 들어 있어서 설치할 건 이거 하나뿐입니다.

Screenlog.dmg 다운로드 59 MB · macOS

설치 방법

1

앱 설치

받은 Screenlog.dmg를 더블클릭하고, 뜨는 창에서 Screenlog를 Applications 폴더로 드래그한 뒤 창을 닫습니다.

2

첫 실행

Apple 정식 인증을 받지 않은 앱이라 처음 한 번은 경고가 뜹니다. 아래 순서를 그대로 따라야 열립니다.

  1. Applications 폴더에서 Screenlog를 찾습니다
  2. control 키를 누른 채 클릭(또는 우클릭) → 열기
  3. "확인되지 않은 개발자입니다" 창에서 다시 열기
그냥 더블클릭하면 계속 막힙니다. 반드시 control+클릭으로 열어야 하고, 이 절차는 처음 한 번만 필요합니다.
3

권한 허용

실행하면 macOS가 순서대로 권한을 묻습니다. 전부 허용해야 정상 동작합니다.

  • 화면 및 시스템 오디오 기록
  • 손쉬운 사용(접근성) — 시스템 설정 화면이 자동으로 열립니다
  • 마이크

권한을 허용할 때마다 앱이 다시 시작될 수 있습니다. 메뉴바(시계 근처)에 ●(녹화 중) 또는 ○(꺼짐) 아이콘이 뜨면 설치가 끝난 것입니다.

기록은 이 컴퓨터에 남습니다

화면과 오디오 기록은 컴퓨터 안에서만 처리됩니다. 이메일, 전화번호, API 키, 주소, 사람 이름은 저장되기 전에 자동으로 가려집니다.

데이터는 ~/.screenpipe-redacted/db.sqlite에 저장됩니다. 권한이 안 잡히거나 메뉴바 아이콘이 안 보이는 등 문제가 생기면 설치 안내 문서의 문제 해결 항목을 참고하세요.
