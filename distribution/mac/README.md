# Screenlog 설치 안내 (Mac)

화면 활동을 기록해서 나중에 검색·질문할 수 있게 해주는 메뉴바 앱입니다.
개인정보(이메일, 전화번호, API 키 등)는 자동으로 가려진 뒤 저장됩니다.
녹화기와 메뉴바 컨트롤(시작/중지, 상태 확인)이 하나의 앱에 같이 들어있어서,
설치할 게 이거 하나뿐입니다.

## 1. 설치

1. `Screenlog.dmg` 더블클릭
2. 뜨는 창에서 `Screenlog`를 `Applications` 폴더로 드래그
3. dmg 창 닫기

## 2. 첫 실행 — "확인되지 않은 개발자" 경고 통과하기

Apple 정식 인증을 받지 않은 프로그램이라 처음 한 번은 경고가 뜹니다. 아래 순서를
**정확히** 따라야 열립니다 (그냥 더블클릭만 하면 계속 막힙니다).

1. `Applications` 폴더에서 `Screenlog` 찾기
2. **control 키를 누른 채 클릭** (또는 마우스 우클릭) → **"열기"** 선택
3. "확인되지 않은 개발자입니다. 그래도 여시겠습니까?" 창에서 **"열기"** 클릭

이 절차는 **처음 한 번만** 필요합니다. 이후로는 그냥 더블클릭하면 됩니다.

## 3. 권한 허용

실행하면 macOS가 순서대로 권한을 물어봅니다. **전부 허용**해야 정상 동작합니다.

- **화면 및 시스템 오디오 기록** 권한
- **손쉬운 사용(접근성)** 권한 — 별도 팝업으로 시스템 설정 화면이 자동으로 열립니다
- **마이크** 권한

권한을 허용할 때마다 앱이 다시 시작될 수 있습니다. 화면 위쪽 메뉴바(시계 근처)에
`●`(녹화 중) 또는 `○`(꺼짐) 아이콘이 뜨면 정상 설치된 것입니다.

권한 화면이 안 뜨거나 실수로 거부했다면, 직접 확인/추가할 수 있습니다:

```
시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록
시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용
시스템 설정 → 개인정보 보호 및 보안 → 마이크
```
각 항목에서 `Screenlog`를 찾아 켜고, 앱을 완전히 종료(`Screenlog` 메뉴 → Quit)한 뒤
다시 실행해야 반영됩니다.

## 4. 메뉴바에서 할 수 있는 것

메뉴바 아이콘(`●`/`○`)을 클릭하면:

- **녹화 상태 확인**, **시작/중지**
- **저장 용량**, **리덕션 처리 현황** 확인
- **지금 동기화**: 지금까지 기록된 걸 색인해서 서버로 보냄
- **동기화 로그 보기**: 동기화가 실제로 잘 됐는지 기록 확인
- **웹 대시보드 열기**: 검색/질문은 여기서 함

## 5. 개인정보 처리 안내

- 화면/오디오 기록은 **컴퓨터 안에서만** 처리되고, 외부 서버로 전송되지 않습니다
  (`--pii-backend local` 설정 — 온디바이스 처리)
- 기록 중 이메일, 전화번호, API 키/비밀번호, 주소, 사람 이름은 자동으로 감지되어
  가려집니다
- 데이터는 `~/.screenpipe-redacted/db.sqlite`에 저장됩니다

## 문제가 생기면

- **메뉴바에 아이콘이 안 보임**: 메뉴바가 아이콘으로 꽉 차서 밀려났을 수 있습니다.
  다른 메뉴바 아이콘을 정리하거나, 메뉴바 빈 공간을 눌러 숨겨진 아이콘을 펼쳐보세요.
- **"port already in use" 에러**: 이미 다른 곳(터미널 등)에서 같은 프로그램이
  실행 중입니다. 기존 걸 끄고 다시 실행하세요.
- **권한을 허용했는데도 안 되면**: 앱을 완전히 종료 후 재실행, 그래도 안 되면
  컴퓨터를 재시작한 뒤 다시 시도하세요.
- 그 외 문제는 관리자에게 문의해주세요.
